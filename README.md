# 北辰连点器 v1.1

基于 Interception 内核驱动的 Windows 鼠标连点工具，点击注入在驱动层完成，对大多数反作弊检测透明。界面使用 ImGui + DirectX 11 渲染。

---

## 系统要求

- Windows 10 / 11（64 位）
- 已安装 Interception 内核驱动（见下方安装步骤）
- **以管理员身份运行**

---

## 安装 Interception 驱动

Interception 驱动需要**单独下载**，本仓库不包含安装程序。

1. 从 [oblitum/Interception](https://github.com/oblitum/Interception) 下载发布包，取出 `install-interception.exe`。
2. 以管理员身份在命令行执行：
   ```
   install-interception.exe /install
   ```
3. **重启计算机**（必须，否则驱动不生效）。

卸载时执行 `install-interception.exe /uninstall` 并重启。

---

## 构建

依赖：CMake 3.20+、MSVC 或 MinGW 工具链。

```bash
cmake -S . -B build -G Ninja
cmake --build build
```

产物：`build/DriverMouseMacro.exe`。构建后会自动将 `external/interception/interception.dll` 复制到 exe 同目录，两者必须放在一起。

---

## 快速上手

1. 确认 Interception 驱动已安装并已重启。
2. **右键** `DriverMouseMacro.exe` → 以管理员身份运行。
3. 启动后**先移动一次鼠标**，顶部统计条的"活跃鼠标"显示 ID 后即可正常使用。
4. 点击底部**开始**按钮，或按配置的热键，连点即开始。

## 首页 — 连点参数

### 点击参数（普通模式）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 循环速度 (ms) | 500 | 每次点击之间的基础间隔 |
| 随机延迟 (ms) | 100 | 每轮循环额外附加 `0 ~ 该值` 的随机抖动，设为 0 则无抖动 |
| 按下时长 (ms) | 10 | 左键按下后持续保持的基础时长 |
| 按下随机延迟 (ms) | 10 | 在按下时长上额外附加 `0 ~ 该值` 的随机抖动 |

右上角三个预设按钮：

- **设为默认**：将当前参数保存为用户默认值（写入 `config.ini`）
- **默认**：恢复到上次"设为默认"时保存的值
- **点射**：循环速度 350ms、随机延迟 20ms、按下时长 30ms

### 休息策略（普通模式和狂暴模式通用）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 点击多少次后休息 | 0 | 设为 0 表示不休息；设为 N 则每 N 次点击后暂停一次 |
| 休息时长 (秒) | 3 | 每次休息持续的秒数 |

## 设置页

### 触发按键配置

默认触发键为**鼠标中键**。支持录制任意组合键：

1. 点击**录制新组合**按钮。
2. 按住目标组合键（支持：Ctrl / Shift / Alt + 鼠标中键 / Button4 / Button5 / F1–F24 / 数字键 / 字母键，最多 4 个非修饰键）。
3. **松开所有按键**后自动确认。

点击**恢复默认**可重置回仅中键触发。

> **注意**：鼠标侧键（中键 / Button4 / Button5）触发时程序会吞掉该事件，不会传递给其他应用。纯键盘热键通过轮询识别，无法拦截传递，建议使用含鼠标侧键的组合。

### 狂暴模式

专为需要交替触发鼠标左键和指定技能键的场景设计。开启后界面整体变红。

循环节奏：
```
左键按下 → 间隔1 → 骑乘键按下 → 循环间隔 → 重复
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 骑乘键 | Left Shift | 每轮循环中触发的技能键，点击"录制"后按下目标键即可更改 |
| 左键按下时长 (ms) | 110 | 左键保持按下的时长 |
| 间隔1 (ms) | 100 | 左键松开到骑乘键按下的间隔 |
| 骑乘键时长 (ms) | 30 | 骑乘键保持按下的时长 |
| 循环间隔 (ms) | 30 | 骑乘键松开到下一轮左键按下的间隔 |

同样支持**设为默认** / **恢复默认**。

> 键盘注入优先使用 Interception 驱动级注入；若键盘设备尚未被识别（未按过任何键），则降级为 `SendInput`。

## 日志页

实时显示所有操作记录，支持按级别过滤：

| 级别 | 颜色 | 含义 |
|------|------|------|
| INFO | 深灰 | 状态变化（启动、停止等） |
| 行为 | 蓝色 | 参数修改、热键触发等用户操作 |
| WARN | 橙色 | 非致命警告（如未检测到鼠标） |
| ERROR | 红色 | 错误信息 |

点击**清空**按钮清空当前日志。日志区自动跟随最新内容滚动。

## 测试页

### 应用状态

三项状态指示灯：

| 项目 | 说明 |
|------|------|
| Interception 上下文 | 驱动初始化是否成功 |
| 活跃鼠标已识别 | 是否已检测到鼠标设备（移动一下鼠标即可点亮） |
| 热键已配置 | 是否设置了有效的触发键 |

### 按键激活检测

点击**开始检测**后，实时显示当前所有按下的按键，可用于确认热键组合是否被正确识别。支持鼠标键、修饰键（区分左右）、F1–F24、字母数字、方向键、小键盘等。

## 配置文件

程序退出时自动将所有参数写入 exe 同目录的 `config.ini`，下次启动时自动读取。直接编辑该文件也会在下次启动时生效。

```ini
[params]
loop_speed_ms   = 500
jitter_ms       = 100
press_base_ms   = 10
press_jitter_ms = 10
clicks_per_rest = 0
rest_seconds    = 3
berserk_enabled   = 0
berserk_mount_vk  = 160   ; 虚拟键码，160 = VK_LSHIFT
berserk_lclick_ms = 110
berserk_gap1_ms   = 100
berserk_mount_ms  = 30
berserk_gap2_ms   = 30

[hotkey]
mouse_btn3 = 1   ; 1 = 启用中键触发
mouse_btn4 = 0
mouse_btn5 = 0
key_ctrl   = 0
key_shift  = 0
key_alt    = 0
vkey0      = 0   ; 附加虚拟键码，0 = 不启用

[defaults]
; "设为默认"按钮写入此处，"恢复默认"从此处读取
loop_speed_ms     = 200
jitter_ms         = 20
press_base_ms     = 200
press_jitter_ms   = 10
clicks_per_rest   = 0
rest_seconds      = 3
berserk_lclick_ms = 110
berserk_gap1_ms   = 100
berserk_mount_ms  = 30
berserk_gap2_ms   = 30
```

## 常见问题

**Q：启动时弹出"无法创建 Interception 上下文"。**  
A：按顺序确认：① 已执行 `install-interception.exe /install`；② 安装后已重启；③ 程序以管理员身份运行。

**Q：统计条显示"请先动一下鼠标"，点击开始无效。**  
A：移动一下鼠标，驱动会将设备 ID 传给程序，随后即可正常使用。若鼠标从未移动直接点击"开始"，程序会降级使用 `MOUSE(0)` 并记录警告日志。

**Q：热键触发后目标程序也收到了按键。**  
A：鼠标侧键触发时程序会吞掉该事件；纯键盘热键无法拦截。建议使用含鼠标侧键的组合。

**Q：程序关闭后鼠标/键盘失灵。**  
A：Interception 驱动拦截所有鼠标输入并通过程序转发，若程序异常退出偶尔会出现此现象。重新以管理员身份启动程序再正常退出可恢复；或直接重启计算机。
